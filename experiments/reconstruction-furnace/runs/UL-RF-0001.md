## Solver-facing evidence policy

The solver receives no historical solution patch, no historical solution PR/commit, no hidden test patch, and no solution-bearing hint cache.

Permitted retrieval is restricted to information that would be legitimately available to an engineer solving the issue at the frozen base revision: repository files/history not containing the future solution, issue/problem statement, dependency documentation where needed, reproducible runtime/build/test evidence, and current tool output.

If a retrieval path unexpectedly reveals the historical solution, emit `CONTAMINATION_EVENT`, stop blind scoring for that task, and replace it.
